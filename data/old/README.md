# Archived inputs

- `gridcharge-data/`: source downloads and auditing pipeline for EV regeneration.
- `office-parking/`: alternative office-parking dataset, original README and ZIPs.
- `switzerland/`: alternative networks, PV profiles, tariffs and five-bus snapshots.
- `EV/`: historical scenario generators.

The active scenario is `../switzerland/5bus/config.json`.
`switzerland/5bus/config_loads_only.json` is the executable baseline used by
`tools/ev_impact.py`; other historical snapshots are not part of the active workflow.
